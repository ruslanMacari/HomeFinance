# HomeFinance

Personal finance management web application built with Spring Boot.

## Prerequisites

- JDK 25 for application compilation and runtime.
- JDK 17 or newer to launch Gradle. The Gradle toolchain resolver can auto-provision JDK 25 when network access is available.
- Docker, required for PostgreSQL and Testcontainers-based integration tests.

## Running the Application

### Everything in Docker

Starts both PostgreSQL and the app:

```bash
docker compose up -d --build
```

The app is available at:

```text
http://localhost:5050
```

### IDE + Docker

Start only PostgreSQL:

```bash
docker compose up -d postgres
```

Then run `homefinance.HomeFinanceApplication` from your IDE. The app uses:

```text
http://localhost:5050
```

The Gradle `bootRun` task also opens a debug port on `5006`.

### Stop Services

```bash
docker compose down
```

## Build And Test

Use the Gradle wrapper:

```bash
./gradlew clean build
./gradlew test
./gradlew bootRun
```

On Windows:

```powershell
.\gradlew.bat clean build
.\gradlew.bat test
.\gradlew.bat bootRun
```

Run a single test class:

```bash
./gradlew test --tests "homefinance.user.service.impl.UserServiceImplTest"
```

Run a single test method:

```bash
./gradlew test --tests "homefinance.user.service.impl.UserServiceImplTest.testMethodName"
```

Test coverage reports are generated by JaCoCo under:

```text
build/reports/jacoco/test/html/index.html
```

## Database

The application uses PostgreSQL 15. Local defaults are:

```text
JDBC_DATABASE_URL=jdbc:postgresql://localhost:5432/homeFinance
spring.datasource.username=postgres
spring.datasource.password=postgres
```

Schema changes are managed by Liquibase from:

```text
src/main/resources/changelog/db.changelog-master.xml
```
